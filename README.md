# Docker Microservices

This repo provides a set of microservices that can be run as self-contained
Docker containers. Each container is designed to be run without having to
orchestrate a set of interacting containers.


## Calibre

Open-source eBook management software with a web-based GUI.

This container supports the following features:
- Locally-hosted eBook library with strong organization features.
- Library accessibility through a web browser.
- Removal of eBook DRM using the
  [DeDRM plugin](https://github.com/Satsuoni/DeDRM_tools.git).
